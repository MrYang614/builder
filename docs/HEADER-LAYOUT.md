# Header 布局增量

2026-10-04。按本轮用户要求调整桌面编辑器的操作布局。原 PRD v0.3 与 A01–A42 的原文保留；本轮明确要求优先于 PRD 3.1 的“文字与图标共同表达”及 3.3 的“打开设置中的外观”路径。窗口仍为单 Tauri WebView、单原生 Three.js Canvas。

新建、打开、保存、另存为、撤销、重做依次位于 Header 左侧。导出、主题、语言、渲染引擎及设置位于右侧；主题图标直接切换亮色／暗色，语言和实际渲染器使用图标选择器。Header 与建模工具操作保留 SVG 图标，说明由本地化 Tooltip 在鼠标悬浮或键盘聚焦时显示。项目名称、未保存状态与底部操作提示继续表达当前工程状态。

后续用户明确移除 Header 的“建筑编辑器”标题，将工程名单独按整个 Header 居中；已保存／未保存修改提示移到撤销、重做右侧。左右等宽网格保留中间名称列，长名称截断，状态沿用既有文案、颜色和工程脏标记。最新要求进一步取消工程名 Tooltip 和键盘焦点，名称为默认鼠标样式的纯展示文本。窄窗口 Header 操作图标保留32px目标。

原生窗口关闭装饰栏，并在 Header 右侧提供最小化、最大化／还原与关闭。整个 Header 的非交互背景、名称、状态和分组间距负责原生移动，双击最大化／还原；按钮、禁用按钮包裹、选择器及其 Portal 菜单保留自己的输入行为。三个实际窗口按钮保留键盘操作，背景和名称不增加焦点目标。关闭通过既有 closeRequested 流程，先等待本机偏好写入，再执行最新工程的保存／放弃／取消保护。浏览器预览没有原生窗口，隐藏这些原生按钮。

## H08 全 Header 拖动与工程名纯展示

当前版本替代 H07 的项目 Tooltip／焦点及独立拖动按钮。HeaderWindow 自己渲染整个 header，并在非交互区域左键首次按下时请求原生 startDragging、双击请求最大化／还原。真实按钮、SVG后代、禁用图标包裹与选择器排除；DOM contains检查阻止React Portal菜单事件误拖动窗口。工程名是普通project-name span，没有tabIndex、title、Tooltip、焦点环或鼠标样式变化；保存状态仍位于左组末尾，工程名仍单独居中。

最新15项相关E2E通过，0失败／跳过／flaky，耗时46.074秒。两语言模拟宿主分别实际点击Header padding、左按钮间隙、保存状态、工程名和右偏好间隙，逐次只请求一次拖动；双击只请求一次拖动和一次最大化。可见SVG按钮、禁用Undo包裹、Select触发及Portal选项均没有拖动请求，未提交“-”数字草稿保持焦点、输入值和工程快照。四双语／主题UI状态测试保留实际Portal、按钮Tooltip、键盘焦点及语义色断言，24个浏览器布局的名称中心偏差0px且名称无Tooltip或焦点入口。

证据在test-results/header-drag-layout，汇总为docs/header-drag-validation.json。质量、四套严格TS、156项／17文件单元与生产构建通过。H08整体仍为已实现未验证：以上验证范围是浏览器真实前端和模拟Tauri IPC，没有启动原生GUI；Windows／macOS实际移动、系统窗口状态、DPI及多屏验收不变。此前窗口适配器9项与Rust18项属于历史基线，本轮没有Rust源码或capability变更。

## H09 双主题直接切换与 H10 启动窗口尺寸

用户最新明确要求仅保留亮色／暗色，移除跟随系统及主题下拉弹窗。此要求覆盖原 PRD 3.3 的三态主题、默认跟随系统和运行期系统同步，以及 A34／A40 中对应条件；原 PRD 与 A01–A42 原文和历史证据保留，当前实现及验收以 H09 为准。Header 主题按钮的 Sun／Moon SVG 表示当前模式，点击或 Enter／Space 直接切换到另一模式；辅助名称保持“外观／Appearance”，暗色时 aria-pressed 为真，悬浮／聚焦描述显示当前模式。语言和渲染器选择菜单继续保留。

本机主题仅保存 light 或 dark。启动脚本、ThemeProvider、应用入口不再查询或监听操作系统主题。已有明确亮／暗偏好保留；旧 system、缺失、无效主题固定迁移亮色，同时保留有效语言与渲染器。Rust 读取执行兼容迁移，保存边界只接受两态，设置仍不进入工程或历史。用户同时要求默认窗口从1280×800改为1600×900；Tauri main 初始尺寸已更新，现有900×600最小尺寸不变。

验证结果、截图与重新构建的 Windows 产物记录在 docs/theme-toggle-validation.json 和 test-results/theme-toggle。H09 浏览器与数据边界结果按本次报告记录；H10 原生启动实际尺寸仍为已实现未验证，没有安装或启动新的宿主，不将浏览器1600×900布局视为操作系统窗口尺寸验收。
