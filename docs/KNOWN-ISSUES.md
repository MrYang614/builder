只支持同厚正交共线／L／T 连接；十字、异厚复杂节点、未知重叠、无法保持连接的反转在提交前拒绝并保留原工程。没有楼梯、自动房间识别、自动补板或坡屋顶。

建筑材质为 PNG／JPEG，单图 32 MiB、8192×8192；环境独立支持 HDR／EXR／PNG／JPEG，单图 64 MiB、单边 8192、总像素 32 Mi。容器 256 MiB，project JSON 32 MiB。资源内嵌、SHA-256 去重，不自动修复原图片自身的不可平铺接缝。

GLB 是用户公开模型输出，含每门独立 Open／Close 动画；JSON glTF 内部 API 不等于已提供多文件菜单。环境保存在工程，PNG 保存当前画面，GLB 不携带全景照明。

锁定光追库仍可能输出 legacy／升级提示，构建保留大 chunk 提示；这些运行库提示与必须零警告的 oxlint 分开。依赖升级或发布前重新审计锁文件，不将旧审计数量当作当前安全结论。
