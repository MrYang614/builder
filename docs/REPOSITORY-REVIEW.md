## 代码质量优化

- Core 按命令、变更集、不可变数据、验证拆分；几何按实体、表面路径、网格拆分。公开 exports 不变。
- Rust storage 按 schema、图片、容器、IO 与测试拆分；Inspector 的完整材质编辑职责进入 MaterialFields，保留选中对象生命周期。
- 五项既有超限例外全部移除。所有手写生产 TS／TSX／Rust 源码统一受 500 行门禁约束，没有提高 ceiling 或新增豁免。
- 几何复用同一份 solids；空墙依赖集跳过平方扫描；表面路径先判断邻接再读取材质／连续组。
- 公共业务／异步／资源入口补充目的与重要约束。未新增全包 lint／类型抑制，固定 Skills 和生成 token CSS 未改变。
- 浏览器测试共享 evidencePath，并可通过 BUILDING_EVIDENCE_ROOT 隔离本轮产物，避免覆盖历史证据。原始失败保留。

共35项确认问题：Core／几何7项、runtime6项、IO／偏好12项、UI／服务10项。独立二审补齐R06的RuntimeBuilding／RuntimePathTracing／ThreeRuntime与ViewportHost清理边界、I10的Rust原生根JSON分类，并发现U10打开期间的新编辑丢失。修复后重跑相关故障注入、完整单元／Rust／构建与受影响浏览器路径；没有将首轮未覆盖的边界写成已验证。

R06二审新增25条故障注入，覆盖真实Three资源事件、runtime owner、Raster／TAA／TSL后处理与tracer呈现材质。项目owner逐项继续尝试释放并保留主错误；只补偿锁定库版本中核对过的自有资源，不承诺任意第三方public disposer内部的所有链都能成功释放。

Node 冷基准原始记录在 test-results/core-geometry-review/evidence.json。2000 无关墙、5 次纯名称变更的 calculateChangeSet 从 942.3774ms 到 4.9156ms；300 无关墙、600 路径的 deriveSurfacePaths 从 259.1631ms 到 109.0311ms。只有单次本机纯计算证据，不代表桌面 FPS、P95 或 Q5 达标。
