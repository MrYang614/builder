Bundled asset: jetbrains-mono-latin-wght-normal.woff2 (40,404 bytes)

Purpose: measurements, numeric fields and technical statistics; tabular numerals.

Only normal Latin variable subsets are referenced by the shared stylesheet.
Both files are included by Vite and require no network connection. Their combined
uncompressed transfer size is 88,660 bytes. font-display: swap provides immediate
fallback text while bundled assets load. Font weights remain variable.

Windows falls back to Segoe UI Variable / Segoe UI and Microsoft YaHei UI.
macOS CJK falls back to PingFang SC. Numeric fallback is Cascadia Code / Consolas,
then the CJK system face. System fonts are not redistributed by Builder.
